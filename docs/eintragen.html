GitHub-Verbindung

Neue Spiele werden direkt in docs/data/games.json im Repository gespeichert. Dafür braucht dieses Gerät einmalig einen GitHub-Token. Er wird nur in diesem Browser gespeichert.

So erstellst du den Token (2 Min.)
  1. Öffne GitHub → Fine-grained token erstellen
  2. Name z.B. Poker eintragen, Ablaufdatum nach Wunsch (max. 1 Jahr)
  3. Repository access: Only select repositories → PokerDashboard
  4. Permissions → Repository → Contents: Read and write
  5. Generate token, kopieren und hier einfügen. Tipp: im Passwort-Manager speichern, dann ist jedes weitere Gerät in Sekunden eingerichtet.
